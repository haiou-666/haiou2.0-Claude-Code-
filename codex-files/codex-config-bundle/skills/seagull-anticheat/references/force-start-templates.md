## Minimum files for external scaffold

- `main.py` with `--demo` and optional `--pid`
- `memory.py` RPM/WPM wrappers
- `structs.py` entity/camera placeholders
- `w2s.py` projection
- `overlay.py` draw loop
- `anticheat_map.md` surface matrix
